## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Profile Manager** | Save named tModLoader mod configurations per playthrough |
| **Dependency Tree** | Visualize mod dependency relationships in your active profile |
| **Multiplayer Sync** | Compare your mod list with friends for session compatibility |
| **Update Tracker** | Flag tModLoader mods with available updates in your profile |
